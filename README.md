# Anurodh Upadhyay

> 	AI Product & Strategy — building production AI agents across AWS, GCP & Azure, each deployed live.

I build agentic systems at the intersection of AI product craft and enterprise infrastructure —
spanning real-time operations, document-grounded RAG, and India's Digital Public Infrastructure (DPI).

## What I Build

- **Voice-enabled, multilingual agents** — AWS Bedrock Agents (Nova Pro) with action-group
  tool loops and RAG over S3 Vectors; five languages, by voice or text
- **Real-time, event-driven systems** — serverless fraud detection on AWS
  (Lambda · SQS · DynamoDB) with a rule engine and AI-generated risk explanations
- **Decision dashboards** — single-file, zero-backend data products on S3 + CloudFront
- **Agentic apps across AWS, GCP & Azure** — Amazon Bedrock (Nova), Vertex AI (Gemini 2.5
  Flash + Google ADK), and Azure AI Foundry (GPT-4.1-mini), all running as live deployments
- **RAG pipelines** — Azure AI Search over SharePoint document libraries, plus
  platform-managed RAG in Copilot Studio (Claude Sonnet 4.6)
- **Microsoft 365 / Power Platform automation** — autonomous Power Automate flows,
  Copilot Studio agents, and Teams Adaptive Card + Outlook alerting

## Selected Projects

- **[ai-grievance-resolution-agent](https://github.com/upadhyayanurodh/ai-grievance-resolution-agent)** —
  Voice-enabled, multilingual grievance-resolution agent on AWS Bedrock Agents (Amazon Nova Pro).
  Deterministic tool-driven resolution + RAG-grounded policy Q&A over an S3 Vectors knowledge base;
  five languages (EN/HI/Hinglish/AR/ES) by voice or text. *[Live demo](https://d2t8lmn9cz1mmx.cloudfront.net)*
- **[ai-upi-fraud-intelligence-agent](https://github.com/upadhyayanurodh/ai-upi-fraud-intelligence-agent)** —
  Real-time UPI fraud detection on AWS. Serverless rule engine over a per-VPA sliding
  window, with Amazon Nova explanations and a live dashboard. *[Live demo](http://upi-fraud-dashboard-339163283135.s3-website.ap-south-1.amazonaws.com)*
- **[fmcg-ai-benchmarking-dashboard](https://github.com/upadhyayanurodh/fmcg-ai-benchmarking-dashboard)** —
  CXO-level dashboard benchmarking enterprise AI adoption across 93 processes & 465 activities
  against global peers. Single file, zero backend, on S3 + CloudFront. *[Live demo](https://d2hzpx71woh3es.cloudfront.net/state_of_ai_scorecard.html)*
- **[ai-gcp-pre-visit-sales-agent](https://github.com/upadhyayanurodh/ai-gcp-pre-visit-sales-agent)** —
  Pre-visit account briefings for field reps. Gemini 2.5 Flash via Google ADK on Vertex AI,
  FastAPI on Compute Engine + Cloud Run. *[Live demo](http://34.187.191.132)*
- **[ai-distributor-trade-intelligence-agent](https://github.com/upadhyayanurodh/ai-distributor-trade-intelligence-agent)** —
  Grounded RAG agent for field sales teams. Retrieves account documents from SharePoint
  via Azure AI Search, surfaces risk flags, and drafts follow-up emails. *[Live demo](https://wonderful-dune-05518d20f.7.azurestaticapps.net)*
- **[copilot-studio-customer-support-agent](https://github.com/upadhyayanurodh/copilot-studio-customer-support-agent)** —
  No-code support agent on Microsoft Copilot Studio (Claude Sonnet 4.6) with
  Power Automate workflow integration and platform-managed RAG.
- **[ai-email-monitor-agent](https://github.com/upadhyayanurodh/ai-email-monitor-agent)** —
  Autonomous Power Automate agent that classifies every incoming Outlook email with
  GPT-4.1-mini and pushes Teams Adaptive Card alerts for urgent messages.
- **[ai-notification-trigger-agent](https://github.com/upadhyayanurodh/ai-notification-trigger-agent)** —
  Azure AI Foundry agent that reads a plain-English situation, assesses severity, and
